# Tripleten web_project_around

Para la construccion de la maqueta dede este proyecto se usaron las propiedades flex, propiedades grid, propiedades de posicionamiento css, la descarga de tipografia y conexión de las mismas por medio de @font-face, el uso de Media Queries para un diseño responsivo/adaptativo en diferentes resoluciones, margenes, codigo html y codigo css.

En este proyecto utiliza la tipografía Inter que fue descargada en la carpeta vendor e importada al proyecto con el archivo css fonts.css, adicional el proyecto responde a 3 tipos de resoluciones gracias al uso de Media queries para tamaños de pantalla de 1280px y 320px.

También se utilizo conceptos basicos de Javascript para hacer que la ventana de editar perfil se cierre y se abra, asi como para guardar la información que entra en los formulario que cambia el titulo de la pagina o que agrega una nueva imagen con su propio título, al igual que para abrir y cerrar las imagenes de los usuarios.

De igual forma se utiliza la validación de los formulados atraves de Javascript para informar a los usuarios de cualquier error al ingresar informacíon en los formularios.Mejoramos también distintos aspectos del usuario a la hora de utilizar nuestros formularios.

Una vez utilizados estos recuersos se paso a refactorizar el codigo incial para transformarlo en un codigo que coincidiera con la metodologia de Programacíon Orientada a Objetos.

En este proyecto aplicamos los conocimiento obtenidos y sumamos aspectos importantes del front-end como al configuración de webpack para la correcta construcción de nuestra página asi como también la incorporación de trabajo con APIs a la hora de recuperar las tarjetas inciales y los datos del usuario, asi como también la actualización de la fotografía de perfil.

Las acciones realizadas en la página web, como modificar el avatar, editar el perfil,añadir cartas y sus acciones (me gusta y eliminar) se procesan a través de solitudes FETCH en una nueva clase llamada API. El procesamiento los errores dentro de catch(). Si la solicitud no puede llegar al servidor o el servidor no responde, se ejecuta el bloque catch().

Tripleten web_project_around
English Translation:

For the construction of this project's mockup, we used flex properties, grid properties, CSS positioning properties, font downloading and connection through @font-face, Media Queries for responsive design in different resolutions, margins, HTML code, and CSS code.

This project utilizes the Inter font, which was downloaded to the vendor folder and imported into the project with the fonts.css file. Additionally, the project responds to 3 types of resolutions thanks to the use of Media Queries for screen sizes of 1280px and 320px.

We also used basic JavaScript concepts to open and close the edit profile window, as well as to save the information entered in the forms, which changes the page title or adds a new image with its own title, and to open and close user images.

Similarly, we use form validation through JavaScript to inform users of any errors when entering information into the forms. We also improved various aspects of the user experience when using our forms.

Once these resources were used, we proceeded to refactor the initial code to transform it into a code that coincided with the Object-Oriented Programming methodology.

In this project, we applied the knowledge obtained and added important aspects of the front-end such as the configuration of Webpack for the correct construction of our page, as well as the incorporation of working with APIs when retrieving the initial cards and user data, as well as updating the profile photo.

The actions performed on the web page, such as modifying the avatar, editing the profile, adding cards and their actions (like and delete), are processed through FETCH requests in a new class called API. Error processing is handled within catch(). If the request cannot reach the server or the server does not respond, the catch() block is executed.
